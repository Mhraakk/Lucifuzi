# نسخه ویندوز ۱۱ و ویندوز ۱۰ (۶۴ بیت)

`public/downloads/Beatris-Setup-Win11-x64.exe` و `Beatris-Setup-Win10-x64.exe` (از صفحه ورود، راهنما و تنظیم کارتخوان دانلود می‌شوند؛ صفحه ورود نسخه همان رایانه را از گزارش مرورگر انتخاب می‌کند) — نصب‌کننده‌های ۶۴ بیتی NSIS از یک اسکریپت (`TARGET=win11|win10`)، بدون نیاز به مدیر سیستم. `Beatris-Setup-x64.exe` نسخه ویندوز ۱۱ است با نام قبلی، برای پیوندهای قدیمی.
- هر دو روی ویندوز ۷ و ۸ یا ۳۲ بیتی نصب نمی‌شوند (مرورگرهای پنجره برنامه دیگر روی آن‌ها اجرا نمی‌شوند).
- نسخه ۱۱ روی ویندوز ۱۰ می‌پرسد و نسخه ویندوز ۱۰ را پیشنهاد می‌کند.
- نسخه ۱۰ اگر Edge جدید یا Chrome نباشد (ویندوز ۱۰ قدیمی فقط Edge قدیم دارد که پنجره برنامه ندارد) صفحه دریافت رایگان Edge را پیشنهاد می‌کند و تا آن وقت در مرورگر پیش‌فرض باز می‌شود.
- برنامه را در پنجره مستقل باز می‌کند (حالت app مرورگر Edge که روی همه ویندوزهای ۱۱ هست؛ نبود Edge → Chrome؛ نبود هر دو → مرورگر پیش‌فرض) با پروفایل جدا در `%LOCALAPPDATA%\Beatris\profile`.
- میان‌بر در منوی استارت و دسکتاپ، آیکن بئاتریس، حذف از «Apps & features».
- به همان سرور زنده وصل است؛ حساب‌ها فقط از کنسول ارائه‌دهنده. `Beatris.cmd` + `beatris.ini` برای تغییر نشانی سرور بدون نصب دوباره.

- **پل کارتخوان** (`pos-bridge.ps1`): همراه نصب می‌شود و با ورود به ویندوز (میان‌بر Startup «Beatris POS») پنهان اجرا می‌شود؛ مبلغ میز معامله را به کارتخوان سامان (PC-POS شبکه) یا برنامه رابط سداد می‌فرستد. spec `docs/specs/0005-pos-bridge.md`.

ساخت: `[FFMPEG=…] bash desktop/windows/build.sh [https://server]` (نیاز: `makensis` ۳ با stubهای amd64 و Node؛ ffmpeg فقط برای ساختن دوباره آیکن، بدون آن همان `beatris.ico` به کار می‌رود؛ هشدارها خطا حساب می‌شوند). آزمون: نصب/حذف بی‌صدا با Wine (`/S`، `LANG=C.UTF-8`) در نقش ویندوز ۱۰، ۱۱ و ۷، با و بدون Edge: هر دو نصب و حذف کامل؛ نسخه ۱۰ بدون Edge مرورگر پیش‌فرض؛ روی ویندوز ۷ نصب نمی‌شود (کد خروج ۲).

امضای دیجیتال ندارد؛ ویندوز بار اول «Windows protected your PC» نشان می‌دهد → More info → Run anyway. برای حذف این پیام گواهی Code Signing لازم است.
