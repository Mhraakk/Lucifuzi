# NNNN — عنوان

- **What:** چه چیزی ساخته می‌شود (یک یا دو خط)
- **Acceptance:** معیارهای پذیرش قابل‌آزمون (هر کدام به یک تست یا بررسی E2E نگاشت شود)
- **Constraints:** must / do not / only / limit to …
- **Out of scope:** آنچه عمداً ساخته نمی‌شود و چرا
- **Verification:** `npm run gate` + بررسی مرورگر یا زنده در صورت نیاز
